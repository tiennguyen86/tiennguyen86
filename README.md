## 👋 Giới thiệu ngắn
Backend engineer ở Việt Nam 🇻🇳, ưu tiên thiết kế API rõ ràng, ổn định và dễ mở rộng. Mình tập trung vào code dễ đọc, truy vấn SQL hiệu quả và quy trình triển khai nhất quán.

## 🎯 Focus hiện tại
- Clean Architecture cho dự án backend
- Docker hóa dịch vụ và cải thiện CI/CD
- Microservices ở mức thực chiến cơ bản
